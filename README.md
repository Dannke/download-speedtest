# Download speedtest

Консольный скрипт на Python: делает 10 последовательных запросов к адресу, каждый раз скачивает ответ целиком
и печатает среднее время запроса, общий объём и скорость скачивания.

## Требования

Python 3.8+. Внешних зависимостей нет, только стандартная библиотека.

## Запуск

```bash
python speedtest.py https://proof.ovh.net/files/10Mb.dat
```

Пример вывода:

```
# 1:    10.49 MB за  3.080 с
...
#10:    10.49 MB за  2.599 с

Успешных запросов:     10 из 10
Среднее время запроса: 2.825 с
Всего скачано:         104.86 MB
Скорость скачивания:   4.75 MB/s (38.00 Mbit/s)
```

## Единицы

- Время: секунды (`с`).
- Объём: мегабайты, **1 MB = 1 000 000 байт** (десятичные, не MiB).
- Скорость: **MB/s** (мегабайт в секунду); в скобках то же в **Mbit/s** (мегабит в секунду, ×8),
  как у провайдеров и speedtest-сервисов.

## Как считается

- Время запроса: полное, от отправки запроса до прочтения последнего байта тела ответа (`time.perf_counter`).
  Сюда входят DNS, установка соединения, TLS и ожидание ответа сервера.
- Среднее время: сумма времён успешных запросов / их число.
- Скорость: общий объём тел ответов / суммарное время скачивания тел, от получения заголовков до последнего байта.
  Установка соединения в скорость не входит, иначе на маленьких файлах она занижалась бы в разы.
- Объём считается по фактически полученным байтам тела (без HTTP-заголовков). Если сервер отдаёт gzip, считается сжатый размер.
- Запросы идут с `Cache-Control: no-cache`, чтобы промежуточные кэши по возможности не отдавали копию.

## Ошибки

Неудачный запрос (HTTP 4xx/5xx, нет сети, таймаут 60 с, обрыв соединения посреди скачивания) печатается
с причиной, и скрипт переходит к следующему. Итог считается по успешным запросам.
Обрыв определяется по `Content-Length`: если получено меньше байт, чем обещал сервер, запрос считается неудачным.

Код выхода: `0`, если все 10 запросов успешны, иначе `1`.

## Тест

```bash
python -m unittest test_speedtest
```

Поднимает локальный HTTP-сервер и проверяет две вещи: что сделано 10 запросов и посчитан весь объём,
и что обрыв соединения посреди ответа засчитывается как ошибка, а не как успешная загрузка.
